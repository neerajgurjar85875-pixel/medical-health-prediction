ℹ️ About Project

Project Overview

MedPredict AI is a Machine Learning based web application designed to estimate medical insurance costs using customer information.

🎯 Objective

The main objective of this project is to use Machine Learning regression techniques to estimate medical insurance charges from customer-related features.

🧠 Machine Learning Workflow

  • Data Collection
  • Data Cleaning
  • Exploratory Data Analysis
  • Feature Preprocessing
  • Model Training
  • Model Evaluation
  • Best Model Selection
  • Web Application Deployment

🛠️ Technologies Used

  • Python
  • Pandas
  • NumPy
  • Scikit-learn
  • Flask
  • HTML & CSS
  • Joblib
